ورقة أوامر لينكس للمبتدئين في الأمن السيبراني

30 أمر هتستخدمهم كل يوم. جرّبهم واحد واحد على جهاز لينكس أو جوه جهاز افتراضي (VirtualBox) بتاعك.

التنقل بين المجلدات

pwdيعرّفك أنت واقف فين دلوقتي
ls -laيعرض كل الملفات (حتى المخفية) بالتفاصيل
cd /var/logينقلك لمجلد معين

التعامل مع الملفات

cat file.txtيعرض محتوى الملف كله
less file.txtيعرض الملف صفحة صفحة (q للخروج)
tail -f app.logيتابع آخر سطور الملف لحظة بلحظة
cp a.txt b.txtينسخ ملف
mv a.txt /tmp/ينقل ملف أو يغيّر اسمه
rm file.txtيمسح ملف (مفيش سلة محذوفات)
mkdir -p lab/notesينشئ مجلد (وكل اللي قبله لو مش موجود)

البحث

grep -rn "admin" .يدوّر على كلمة جوه كل الملفات
find / -name "*.conf" 2>/dev/nullيدوّر على ملفات بالاسم
which python3يعرّفك مكان برنامج معين
file mystery.binيعرّفك نوع الملف الحقيقي

الصلاحيات

ls -lيعرض صلاحيات الملفات
chmod 640 secret.txtيغيّر صلاحيات الملف
chown user:group fileيغيّر مالك الملف
sudo -lيعرض اللي مسموحلك تشغّله بصلاحية أعلى

العمليات

ps auxيعرض كل العمليات الشغالة
topيعرض استهلاك الجهاز لحظيًا (q للخروج)
kill -9 1234يقفل عملية برقمها بالقوة
systemctl status sshيشوف حالة خدمة

الشبكة

ip aيعرض عناوين الشبكة بتاعتك
ss -tulpnيعرض البورتات المفتوحة على جهازك
ping -c 4 8.8.8.8يجرّب الاتصال بجهاز تاني
curl -I https://example.comيجيب هيدرز موقع من غير ما يفتحه
nmap -sV 192.168.1.10يفحص بورتات جهاز ويعرّف إصدار الخدمات (بتصريح فقط)

معلومات عن النظام

whoamiاسم المستخدم الحالي
idالمستخدم والمجموعات اللي تابع ليها
uname -aإصدار النظام والـKernel
تنبيه قانوني: استخدم الأوامر دي على أجهزتك الشخصية أو في بيئات تدريب مصرّح بيها فقط. فحص أو دخول أجهزة مش بتاعتك من غير تصريح كتابي مخالف للقانون.
